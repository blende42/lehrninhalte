# Projekte

Dieser Ordner enthält grössere, zusammenhängende Mini-Projekte. Projekte unterscheiden sich von normalen Übungen dadurch, dass sie mehrere bisherige Konzepte kombinieren und mehr Eigenständigkeit bei Planung, Umsetzung und Reflexion verlangen.

Projekte dienen dazu, bekannte Grundlagen in einem realistischeren Zusammenhang anzuwenden. Sie fördern Transfer, Entscheidungen im Code und die Fähigkeit, ein kleines Vorhaben über mehrere Arbeitsschritte hinweg strukturiert umzusetzen.

Lernenden- und Lehrpersonen-Versionen werden getrennt geführt:

```text
Projekte/<Projektname>/README.md
Projekte/<Projektname>/Lernende/Projektauftrag_<Projektname>.md
Projekte/<Projektname>/Lehrperson/Projektauftrag_<Projektname>_LP.md
```
