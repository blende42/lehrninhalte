# Lagerverwaltung Light

Status: Projektauftrag ausgearbeitet.

`Lagerverwaltung Light` ist ein Mini-Projekt, in dem Lernende eine einfache Lagerverwaltung selbständig strukturieren und umsetzen.

Das fachliche Umfeld ist eine kleine Lagerverwaltung mit Produkten, Preisen und Lagerbeständen. Produkte werden aus einer CSV-Datei geladen, angezeigt, verkauft, ergänzt und wieder gespeichert.

Der technische Rahmen schliesst an die bisherige Java-Sequenz an. Das Projekt verbindet Klassen und Objekte, Kapselung, `ArrayList`, Methoden, Maven, Packages, CSV-Persistenz, JUnit-Tests, Verantwortlichkeiten, Interfaces, Polymorphie und Wiederverwendung.

Das Projekt ist bewusst kein kleinschrittiges Übungsblatt. Die Lernenden erhalten klare Anforderungen und technische Leitplanken, entscheiden aber selbst über eine sinnvolle Struktur.
